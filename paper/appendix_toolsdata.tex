\section{External tools and dataset manifest}
Program requirement: 40 external tools and 120+ accession-level datasets per
project, honestly counted. This manifest is regenerated as the counts move;
the detailed resource list and its evidence files are in the repository docs and results directories. Counting rule: datasets are accession-level and actually
used; one study's condition matrix is one dataset; no padding.

\subsection{Research/data tools and science libraries (strict audit below 40; target 40)}
The historical forty-item resource table is preserved in \texttt{docs/EXTERNAL\_TOOLS.md}; it is not a strict tool count. The research/data services and science libraries actually used include ViennaRNA, PyTorch, scikit-learn, Biopython, NumPy, pandas, SciPy, matplotlib, NCBI E-utilities, figshare REST, RefSeq, primer3-py and the implemented rule-based or trained scorers. Those implemented comparators include Azimuth/Rule Set 2, Lindel, Rule Set 1, SSC, CRISPRscan, CCTop, CROP-IT, CRISPRoff, Chari and WU-CRISPR. Each implementation's benchmark is linked from the resource ledger and result files. No reference-only publication, dataset, pytest, git, TeX or hosting service counts toward the 40 scientific tool requirement. The strict target remains open.

\paragraph{Strict audit caveat.} The older 40-item resource inventory included infrastructure (pytest, git, TeX), paper-only references, and datasets. Those entries are not forty independently used research/data tools. The 111 RefSeq transcript accession records are distinct fetched-and-scored sequences, but come from the same source; collapsing all records by source-study leaves far fewer than 120 independent studies. The dataset threshold is met only under the stated accession-record interpretation, not under independent-study counting.\\
