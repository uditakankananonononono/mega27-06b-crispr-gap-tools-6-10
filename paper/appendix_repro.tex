\section{Reproducibility register}
Every quantitative claim in this manuscript maps to one script, one input
dataset, and one committed results file. All scripts run CPU-only
(${\leq}2$ cores, ${\leq}2$~GB RAM) and are executed with
\texttt{PYTHONPATH=.} from the repository root. Environment: Python 3.10,
NumPy 2.2.6, pandas 2.3.3, SciPy 1.15.3, scikit-learn 1.7.2, PyTorch
2.14.0+cpu, ViennaRNA 2.7.2 (duplexfold/RNAfold). Deep models seed all
samplers explicitly; scikit-learn models use \texttt{random\_state=0}.

\subsection{Determinism and contamination guards}
Three guards make the pipeline failure-visible. (1) The FC+RES loader
enforces \texttt{drug != 'nodrug'} so FC test guides cannot leak into
training; a hermetic test asserts the filter (added after the retraction
documented in the negative-results register). (2) Every benchmark script
verifies 30-mer-set disjointness between train and test before fitting;
the V2 pull was accepted only after V2/V1 overlap was verified to be zero.
(3) All reported numbers are read into the manuscript from the committed
JSON results files, not recomputed by hand --- the extended-validation
appendix quotes them verbatim.

\subsection{Live-network steps}
Two scripts touch the network: \texttt{riskflag\_refseq\_panel.py}
(NCBI E-utilities; resumable, appends per-accession records) and the
one-time dataset pulls recorded in \texttt{data/PROVENANCE.md} with exact
URLs (figshare file IDs, GitHub raw paths). Everything else is hermetic;
the 40-test pytest suite runs fully offline.
